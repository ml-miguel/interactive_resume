# Interactive Resume — RAG-агент для ответов о проектах

Интерактивное резюме: RAG-агент, который отвечает на вопросы о моих проектах, используя поиск по эмбеддингам и генерацию через GigaChat.

## О проекте

Агент принимает вопрос на естественном языке (например, «Работал ли ты с PyTorch?») и:
1. Находит наиболее релевантные проекты по семантическому сходству.
2. Формирует ответ на основе найденного контекста с помощью LLM.
3. Указывает, какие проекты были использованы для ответа.

Проект демонстрирует полный RAG-пайплайн: эмбеддинги → поиск → генерация.

## Стек

- Python 3.10+
- sentence-transformers (`deepvk/USER-bge-m3`)
- scikit-learn (косинусная близость)
- GigaChat API (LangChain)
- NumPy

## Установка

pip install -r requirements.txt
Настройка
При первом запуске скрипт запросит ключи GigaChat и сохранит их в data/.env:

Client ID — из личного кабинета GigaChat

Access Token — там же

Scope — оставьте GIGACHAT_API_PERS (для физических лиц)

Альтернативно можно создать data/.env вручную на основе data/.env.example.

## Запуск
bash
python interactive_resume.py
Пример сессии:

Интерактивное резюме. Задай вопрос о проектах.

Вопрос: Работал ли ты с PyTorch?

Найденные проекты:
  - IMDB Reviews Classifier (сходство: 0.612)
  - MNIST Classifier (сходство: 0.547)

Ответ: Да, кандидат работал с PyTorch. В проекте IMDB Reviews Classifier 
использовался PyTorch и DistilBERT для классификации тональности отзывов 
(точность 90.48%). В проекте MNIST Classifier — PyTorch для распознавания 
рукописных цифр (точность 97.46%).
Для выхода введите выход, exit или quit.

## Как это работает
Загрузка проектов. Все проекты хранятся в projects.json и превращаются в текстовые описания.

Эмбеддинги. Модель deepvk/USER-bge-m3 кодирует каждое описание в вектор.

Поиск. Запрос пользователя кодируется тем же способом, затем находится топ-2 проектов по косинусной близости.

Генерация. Найденные проекты передаются в GigaChat вместе с вопросом. Модель отвечает, используя только контекст проектов.

Обновление базы проектов
Чтобы добавить новый проект, просто допишите его в projects.json:

json
{
    "name": "Название проекта",
    "description": "Что делает проект",
    "stack": "Использованные технологии",
    "result": "Результат / метрики",
    "link": "https://github.com/..."
}
Эмбеддинги пересчитываются автоматически при следующем запуске.

## Примечания
При первом запуске модель deepvk/USER-bge-m3 (~2 ГБ) скачивается с Hugging Face. Это может занять несколько минут.

Для работы требуется доступ к GigaChat API и интернет.
